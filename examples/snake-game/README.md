# 贪吃蛇：finx 首个交付的验收产物

`index.html` 是 finx 驱动 DeepSeek 的 `deepseek-flash` 模型，从空目录开始自主写出来的，生成后没有人工改动。用浏览器直接打开就能玩：方向键或 WASD 控制方向，空格暂停，回车重开。

## 生成方式

在空目录中执行：

```bash
finx exec --permission-mode bypass-permissions --thinking medium "<下面的需求>"
```

需求原文：

```text
写一个贪吃蛇小游戏。要求：
1. 用 HTML、CSS、JavaScript 实现，全部写在当前目录的 index.html 一个文件里，用浏览器直接打开即可运行，不依赖任何外部资源；
2. 方向键或 WASD 控制方向，不能直接掉头；
3. 吃到食物后蛇身变长、加分，速度随分数逐步加快；
4. 撞墙或撞到自己时游戏结束，显示得分，按回车或点击按钮重新开始；
5. 显示当前分数和最高分（最高分用 localStorage 保存）；
6. 空格键暂停/继续。
写完后用 read 重新检查一遍代码并修正问题。不要尝试打开浏览器。最后简要说明玩法。
```

| 项 | 结果 |
|---|---|
| 模型 | `deepseek/deepseek-flash`，推理等级 medium |
| 耗时 | 210 秒，退出码 0 |
| 模型调用 | 13 次 |
| 工具调用 | 15 次：bash 10、read 3、write 1、edit 1 |
| Token | 输入 505,300（缓存命中 475,904），输出 37,590 |

`finx-session.jsonl` 是这次运行的会话日志，由 finx 原样写出，未经编辑，可以看到每一轮的模型输出和工具调用。

## 浏览器实测（2026-10-28）

以下各项全部通过：

- 点击按钮开始；方向键和 WASD 都能转向，蛇向右走时按 A 不会掉头
- 空格暂停、再按继续
- 吃到食物加 10 分、蛇身变长；50 分时升到 Lv.2 并加速
- 撞墙、撞到自己都会结束，并显示本局得分和最高分
- 回车和"再来一局"按钮都能重开，分数清零，最高分保留
- 最高分写入 localStorage，刷新页面后仍在

"吃食物"和"撞自己"两项测试固定了随机数，让食物出现在蛇的前进路线上，以便确定性地复现；游戏代码本身没有改动。
