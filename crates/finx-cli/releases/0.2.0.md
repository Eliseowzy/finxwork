The first public release of the finx CLI.

- An interactive mode in the terminal: `finx`, `finx "PROMPT"`, `finx resume`
- `finx exec` for scripts and CI, with one JSON result or an event stream, and exit codes that tell what happened
- `finx serve` (JSON-RPC) and `finx acp` (editors)
- `finx login` for API keys, Token Plans, a ChatGPT subscription, a local model or your own compatible service
- Tools for files, commands, sub-agents, web search, workbooks; PDF, browser and computer use as components
- MCP servers and Skills
