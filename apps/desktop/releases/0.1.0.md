FinxWork 首个公开版本发布，专为金融行业人士打造的智能工作台。

### 核心特性
- **BYOK 与现有订阅直连**：支持 ChatGPT 订阅（OAuth）、千问办公与 Qoder 本机账户直连，内置阿里云百炼、腾讯云、火山方舟、智谱 GLM 等 Token Plan / Coding Plan，并支持各大商业 API Key 与私有/本地模型端点（如 Ollama）。
- **财务建模与电子表格**：原生读写 `.xlsx`、`.csv`、`.tsv` 与只读 `.xls`，支持公式重算、结构化引用展开、循环引用检测与影响面追踪。
- **研报文档与幻灯片**：内置 PDF 阅读与区域引用、Word（`.docx`）协同编辑与 PDF 导出，以及 `.pptx` 高清渲染与局部编辑。
- **浏览器协同与扩展**：配套 Chrome 扩展与原生浏览器控制、MCP 服务、自定义 Skills、专属 Bot 与定时任务（Routine）。
- **本地优先与安全审批**：零遥测上报，修改先落工作副本，关键操作需经权限确认。
