# 2026-11-08 内存探测的原始输出

本文件配合 1108-frontend-performance-report.md 的 §8。机器、构建和运行方式同报告 §3；负载都是 bots=0,sessions=10000,projects=100,messages=5000，对话是同一段 6004 条的会话。
除 A 段的 memory-infra 分项外，数字都是 macOS vmmap -summary 的物理占用（footprint），每次测之前先做一次垃圾回收、再等 2.5 秒。
"read back" 指从最后一页一页往回读到第一条；"left" 指读完后点侧栏回到新会话页。
原始输出只删掉了本机路径和空行。

## H. 隐藏后释放：真实的隐藏和最小化（2026-11-08 补测，438cb9d0）

第一组保留后台模式的调试会话：hide() 和 minimize() 之后页面仍然是 visible，没有 visibilitychange 事件，所以没有释放。
