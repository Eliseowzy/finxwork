## 方案摘要

- **要做的事**：点回复里的文件，在会话页右侧的文件面板里打开并定位到行；文本和代码可以直接改，改完自动保存；左边有项目的目录树。
- **界面**：
  - 右侧一栏，和内置浏览器、后台任务卡片同一个位置，同一时间只显示一个；可以展开占满、可以关闭；
  - 上面是打开的文件标签，下面一行是路径、保存状态和"⋯"菜单；
  - 主体左边是编辑器或预览，右边是可以收起的目录树。
- **编辑**：
  - 编辑器用 CodeMirror 6，按需加载；
  - 停止输入 1 秒自动保存，⌘S 立即保存；
  - 保存时比对内容哈希，磁盘上的文件变了就不覆盖，让人选"载入磁盘版本"或"仍然保存"。
- **预览**：Markdown 默认渲染、可以切到源码，图片直接显示，二进制和太大的文件说明原因并给"用默认应用打开"。
- **外部改动**：内核监听打开的文件和展开的目录；没有未保存的修改就直接刷新，有就提示。
- **内核**：新增 `files/list`、`files/read`、`files/write`、`files/watch` 和通知 `files/changed`。
  - 保存在会话的文件锁里做，和模型的编辑工具用同一把锁，所以两边的写入会排队，不会互相覆盖；
  - 写盘复用工具已有的原子写。
- **不在这一期**：改动面板（差异视图）、表格和 PDF 预览、把选区加进对话、模型主动打开面板。
- **工作量**：约 5 天（§12）。

## 1. 现状

- 回复里的文件标签用默认应用或选定的编辑器打开（content-actions-design §4）。看一眼文件也要离开应用，跳到别的程序里。
- 自定义页的技能详情有一个只读的文件浏览器：左边目录树，右边文件内容；Markdown 和 SVG 渲染，可以切到源码；图片直接显示。
- 会话页右侧已经有两种面板：内置浏览器（单独一栏，可拖动宽度、展开、关闭），以及后台任务卡片。
- 内核里已有的相关能力：
  - 工具的原子写（临时文件、落盘、改名替换；保持链接和权限，拒绝只读文件）；
  - 按会话的文件锁，模型的编辑和写入工具都会拿；
  - 模型读过的文件版本记录：文件被别人改过，模型的编辑会被拒绝，要它先重读；
  - 基于 notify 的目录监听（自定义页在用）；
  - 图片按文件头识别。

## 2. 目标

| 编号 | 目标 | 说明 |
|---|---|---|
| G1 | 一点就看 | 回复里的文件、步骤里读过和改过的文件，点一下就在旁边打开，定位到行，对话不动 |
| G2 | 顺手就改 | 看到要改的地方直接改，不用找保存按钮，也不用切到别的编辑器 |
| G3 | 不丢、不盖 | 不丢用户没存的修改；不覆盖别人（模型、别的编辑器、命令）刚写进去的内容 |
| G4 | 与应用一致 | 栏位、标签条、按钮、菜单、配色沿用内置浏览器面板和现有令牌 |
| G5 | 不拖慢 | 编辑器按需加载；目录只读展开到的那一层；目录树虚拟滚动 |

## 3. 界面

### 3.1 位置

- 会话页右侧单独一栏，和内置浏览器面板的位置、宽度规则相同：
  - 可以拖动左边缘改宽度，宽度单独记住；
  - 可以展开到除了边栏以外的整个窗口（对话保持挂载，只是不显示），再点还原；
  - 收起面板时，打开的文件仍然留着，下次打开面板还在。
- **同一时间只显示一个**：文件面板、内置浏览器、后台任务卡片。打开其中一个，另外两个让开。
  - 模型第一次打开网页时，浏览器面板原本会自己出来；文件面板开着时不再抢位置。
- 会话顶栏加一个"文件"按钮，放在浏览器按钮左边，点它打开文件面板。图标是文件夹（`folder`）：这个面板看的是工作区的文件和目录树，以及从对话里点过来的文件；改动视图是下一期的事，到时另配标志。
- 面板打开时，这个按钮从顶栏移到面板标签条的最右端（窗口最右边），保持高亮，点它收起面板；它取代了 ×。它左边是放大或还原。面板收起后，按钮回到顶栏。内置浏览器面板同样如此（browser-design.md）。

### 3.2 结构

```
┌ 标签条 ─────────────────────────────────────────────┐
│ [app.ts ●] [报告.md] [logo.png]  未保存 </> ⋯ 🌲 │ ⤢ [📁] │  ← 文件的工具 │ 面板的按钮
├ PDF 的工具行（只有 PDF 有）────────────────────────────┤
│ ☰ ✎ │ 1 / 7        − 53% +                       🔍 │
├──────────────────────────────────────────┬──────────┤
│ 编辑器或预览                              │ 目录树    │
│  1  import …                             │ ▾ src    │
│  3  export async function start() {  ←高亮│   app.ts │
│                                          │ ▸ docs   │
├──────────────────────────────────────────┴──────────┤
│ ⚠ 磁盘上的这个文件变了      载入磁盘版本   仍然保存   │  ← 只在需要时出现
└─────────────────────────────────────────────────────┘
```

- **标签条**（44 像素，和浏览器面板的一样）：
  - 每个打开的文件一个标签：类型图标、文件名、关闭按钮；
  - 有未保存的修改时，关闭按钮的位置显示一个圆点，悬停变回 ×；
  - 标签太多时横向滚动。
  - 标签占满中间，右端两组按钮，中间一条竖线隔开：
    - 当前文件的工具：保存状态（已保存 / 未保存 / 保存中 / 只读，说明原因）、Markdown 和 SVG 的"源码"开关（按下是源码，抬起是预览）、"⋯"（打开方式 › / 在访达中显示 / 拷贝路径 / 拷贝相对路径，和文件标签的右键菜单是同一个，只是少了"打开"）、目录树开关；
    - 面板的按钮：展开或还原，最右边是文件按钮（顶栏移过来的，点它收起面板）。展开时，边栏隐藏的话，左端先放边栏按钮（同浏览器面板）。
  - 面板窄于 560 像素时，保存状态的文字先让给标签：未保存看标签上的圆点，只读的标签图标换成锁。
  - 不再显示文件路径（2026-11-03 改）：悬停标签看路径，"⋯"里可以拷贝。
- **PDF 的工具行**（36 像素，只有 PDF 有）：目录与缩略图、框选、页码、缩放、搜索（document-editor-design §7.2）。
- **目录树**：在编辑区右边（用户的选择），宽 200 像素，可以收起，收起状态记在会话里（§8）。
- **主体**：编辑器（§5）或预览（§3.3）。
- **底部提示条**：只在冲突、外部改动、保存失败时出现（§6、§7）。

### 3.3 不同的文件

| 文件 | 显示 |
|---|---|
| 文本和代码 | 编辑器，按扩展名着色，可以改 |
| Markdown | 默认显示渲染结果（和回复同一个渲染器），标签条多一个"源码"开关；源码就是编辑器 |
| SVG | 默认按图片显示，可以切到源码 |
| PNG、JPEG、GIF、WebP | 图片居中显示，不超过面板 |
| UTF-16、GBK 等非 UTF-8 文本 | 编辑器只读，标签条写"只读 · GBK 编码"，标签图标是锁，避免存回去时改了编码 |
| 二进制、超过 5 MB 的文本、超过 10 MB 的图片 | 一张说明卡：文件名、大小、为什么不显示，按钮"用默认应用打开""在访达中显示" |
| 找不到 | 说明卡"找不到这个文件"，标签保留，可以关掉 |

## 4. 打开文件

### 4.1 入口

| 入口 | 动作 |
|---|---|
| 回复里的文件标签，左键 | 在面板里打开，定位到行（content-actions-design §4.2 的左键随之改变） |
| 文件标签的右键"打开" | 同上 |
| 文件标签的右键"打开方式 ›" | 用系统默认应用或某个编辑器打开（保留，不再记"默认编辑器"） |
| 文件夹标签，左键 | 在项目里：打开面板，目录树展开到这个文件夹；在项目外：在访达中打开 |
| 读取、编辑类步骤的右键"打开" | 在面板里打开；读取带 `offset` 时定位到那一行 |
| 会话顶栏的"文件"按钮 | 打开或关闭面板；还没有打开的文件时，显示展开的目录树和一句"选一个文件打开" |
| 目录树里点文件 | 在面板里打开 |

### 4.2 打开时

- 已经打开的文件：切到它的标签，再定位到行。
- 定位：
  - 行号所在的行（或行号区间）用淡黄色底标出，滚到面板中间偏上；
  - 光标放在那一行开头；
  - 之后点别处，标记保留，直到下一次定位或关闭标签。
- 一打开就会运行的文件（`.command` 等）：在面板里只是显示它的文字，不会运行，所以不再特殊处理；"用默认应用打开"仍然受原来的保护（content-actions-design §4.4）。

## 5. 编辑器

- **CodeMirror 6**：编辑和显示的状态机在它自己里面，React 只管外壳。
  - 按需加载（动态 import）：主包不变大，第一次打开文件时才下载编辑器；
  - 语言按文件名找（`@codemirror/language-data`），也是用到时才加载。
- **功能**：
  - 行号、当前行高亮、括号匹配和自动补全括号、代码折叠、多光标；
  - 搜索替换（⌘F，见下）、撤销和重做；
  - 显示选中文字的其他位置。
  - Tab 键缩进；按 Esc 再按 Tab 可以离开编辑器。
- **自动换行**：Markdown 和纯文本自动换行，代码不换行。
- **配色**：
  - 一套随浅色、深色切换的语法颜色（CSS 变量），向对话里代码块用的 GitHub 配色靠；
  - 背景、选区、光标、行号用应用自己的令牌；
  - 字体用应用的等宽字体，12.5 像素。
- **换行符**：文件里是 `\r\n` 的，编辑器按 `\r\n` 分行，存回去还是 `\r\n`。
- **快捷键与应用菜单**：
  - ⌘Z、⇧⌘Z 走系统的撤销重做，编辑器直接接住；
  - ⌘F 在应用菜单里是"搜索"，编辑器有焦点时改为打开编辑器自己的查找；
  - ⌘S 保存（菜单里没有占用）。
- **状态保留**：
  - 每个标签保留自己的编辑状态（内容、撤销历史、光标、选区）和滚动位置；
  - 切换标签、关掉再打开面板、切到别的会话再回来，都还在。应用退出后不保留。

## 6. 保存与冲突

### 6.1 什么时候存

- 停止输入 1 秒后自动保存。
- ⌘S 立即保存。
- 关闭标签、关闭面板、切到别的会话、窗口隐藏时，有未保存的修改先保存。
- 只读文件、正在冲突的文件不自动保存。

### 6.2 怎么存

```
页面：files/write { session_id, path, text, base_hash }
内核：拿会话的文件锁
      → 读磁盘上的当前内容，算 SHA-256
      → 和 base_hash 不同：返回"冲突"和当前哈希，不写
      → 相同：原子写（临时文件 → 落盘 → 改名），返回新哈希
页面：新哈希成为下一次保存的基线
```

- **基线**：打开时读到的哈希，之后每次保存成功后返回的哈希。
- **保存时又改了**：保存期间继续输入的内容，等这次保存回来，用新哈希再存一次。不会两次保存同时发出。
- **和模型的编辑排队**：模型的编辑和写入工具也拿同一把锁。用户保存和模型改文件不会交错，比对哈希和写入之间不会被模型插进来。
  - 别的程序（用户自己的编辑器、终端里的命令）不拿这把锁，那一段时间窗很短，靠哈希比对兜底，不承诺绝对不覆盖。
- **模型这边不用改**：用户存完，文件的版本变了。模型下次编辑这个文件会被要求先重读，不会用旧内容覆盖用户的修改。
- **UTF-8 带 BOM 的文件**：存回去仍然带 BOM。

### 6.3 冲突

保存时发现磁盘上的版本已经不是基线：

- 底部提示条："这个文件在别处被改过了"，两个按钮：
  - **载入磁盘版本**：放弃这里没存的修改，换成磁盘上的内容；
  - **仍然保存**：用这里的内容覆盖（`base_hash` 留空）。
- 文件已被删除：提示"这个文件已被删除"，按钮是"关闭"和"重新保存"。
- 冲突期间可以继续改，不会自动保存。

### 6.4 失败

- 写不进去（只读文件、没有权限、磁盘满）：提示条写明原因，保留修改，下次输入后再试。
- 被拒绝（finx 自己的运行数据，§9.4）：提示"这是 finx 的运行数据，不能在这里修改"，编辑器转为只读。

## 7. 外部改动

- **页面告诉内核要盯什么**：打开的文件和展开的目录，用 `files/watch` 告诉内核，有变化就收到 `files/changed`。等 0.3 秒把同一批变化合起来再通知。
- **打开的文件变了**：
  - 没有未保存的修改：重新读，直接换上新内容，光标和滚动位置尽量留在原处；
  - 有未保存的修改：提示条"磁盘上的这个文件变了"，按钮同冲突（载入磁盘版本、仍然保存）。
- **展开的目录变了**：重新读那一层。
- **窗口回到前台**：当前标签再读一次哈希，补上没收到的通知。

## 8. 目录树

- **根**：会话的项目目录。没有项目的会话，就是它自己的文件夹。
- **按需读取**：一次只读展开的那一层（`files/list`），每个目录的结果单独缓存。展开状态、选中项属于界面状态，按会话保存在内存里。
- **显示规则**：
  - 文件夹在前，文件在后，各按名字排（数字按大小排，不分大小写）；
  - 隐藏 `.git` 和 `.DS_Store`；
  - `.gitignore` 忽略的条目这一期不置灰（DQ-44）。
- **虚拟滚动**：先根据展开状态算出当前要显示的行，再交给虚拟滚动（`@tanstack/react-virtual`）。几千个文件也只渲染看得见的几十行。
- **行**：缩进、展开箭头、图标、名字；当前标签对应的文件高亮。
- **操作**：
  - 点文件夹展开或收起，点文件打开；
  - 右键是文件或文件夹的菜单，和回复里文件标签的菜单相同；
  - 键盘：上下移动，左右收起和展开，回车打开。
- **定位**：打开的文件在项目里时，展开到它所在的目录，滚到它那一行。

## 9. 内核与协议

### 9.1 方法

| 方法 | 参数 | 结果 |
|---|---|---|
| `files/list` | `session_id`，`path`（目录：绝对路径，或相对会话目录；空字符串就是会话目录） | `path`（绝对），`entries`（`name`、`dir`、`link`、`size`），`truncated`（超过 5000 项时只给前 5000 项） |
| `files/read` | `session_id`，`path` | `path`、`size`、`kind`（text、image、binary、too_large），以及：`hash`（SHA-256，十六进制）、`text`、`encoding`、`writable`、`image`（`mime_type`、base64 数据） |
| `files/write` | `session_id`，`path`，`text`，`base_hash`（留空表示照写） | `status`（saved、conflict、refused），`hash`（saved 时是新的，conflict 时是磁盘上当前的，文件没了就不给），`message` |
| `files/watch` | `session_id`，`paths`（文件和目录） | 空。替换这个连接对这个会话的监听集合，空列表就是停止 |
| 通知 `files/changed` | `session_id`，`paths`（监听集合里变了的那些） | — |

- 路径按会话的规则解析：`~`、`file://`、相对会话目录，去掉 `.` 和 `..`，和模型的工具一样。
- 会话必须已经加载。桌面端显示一个会话时就已经附着到它，所以总是满足；没加载时返回"会话未加载"。
- 协议版本不变：只加方法，不改已有方法。

### 9.2 读取

- 先看大小：
  - 文本超过 5 MB 是 `too_large`；
  - 图片按文件头认（PNG、JPEG、GIF、WebP），超过 10 MB 是 `too_large`，否则给 base64；
  - SVG 是文本。
- 文本的判断：
  - UTF-8 带 BOM：`utf-8-bom`，去掉 BOM 给文字；
  - UTF-16（看 BOM）：解码，只读；
  - 前 8 KB 有零字节：`binary`；
  - 是合法的 UTF-8：`utf-8`；
  - 否则按 GB18030 试解码（中文的 GBK 文件都在里面），成功就只读，失败就是 `binary`。
- 哈希是整个文件字节的 SHA-256，`files/write` 拿它来比。

### 9.3 写入

1. 解析路径；属于 finx 运行数据的拒绝（§9.4）。
2. 拿会话的文件锁（和模型的编辑、写入工具同一个）。
3. 读磁盘上的当前内容：
   - 存在且不是合法的 UTF-8：拒绝（不改编码）；
   - 和 `base_hash` 不同：返回冲突和当前哈希；
   - 文件不存在而 `base_hash` 不为空：也是冲突（文件被删了）。
4. 当前文件带 UTF-8 BOM，写回时加上。
5. 用工具的原子写写入。
6. 返回新内容的哈希。

### 9.4 不允许写的

- 用户在面板里改文件是用户自己的操作，`.git`、`.vscode`、`.ssh` 这些模型改之前要问的路径，这里不拦。
- 只拒绝 finx 自己的运行数据：会话日志与会话数据（`~/.finx/sessions`）、日志（`~/.finx/logs`）、服务运行目录（`~/.finx/run`）。
- `~/.finx/config.toml`、`models.toml`、技能文件、没有项目的会话文件夹（`~/.finx/chats`）都可以改。

### 9.5 监听

- 每个连接、每个会话一个监听集合。
- 文件监听它所在的目录（编辑器常用改名替换的方式保存，只盯文件会跟丢）。
- 一个目录被多个集合用到时只监听一次；没人用了就取消。
- 连接断开时清掉它的全部集合。
- 复用自定义页的监听封装，合并等待 0.3 秒。

## 10. 文件状态

文件状态放在组件外面（页面的一个按会话分组的仓库），组件只订阅。这样列表虚拟滚动、切换会话、面板收起，都不会丢状态。

每个打开的文件：

| 字段 | 含义 |
|---|---|
| `path`、`rel`、`name` | 绝对路径、相对项目的路径、文件名 |
| `kind`、`encoding`、`writable` | 来自 `files/read` |
| `disk` | 最近一次读到或存成功的内容和它的哈希（基线） |
| `editor` | CodeMirror 的编辑状态：内容、撤销历史、选区 |
| `dirty` | 编辑器内容和基线不同 |
| `save` | idle、saving、conflict、deleted、failed、refused |
| `target` | 要定位的行或行区间，带一个序号；同一位置再点一次也会重新定位 |
| `scroll` | 滚动位置 |

- 保存的排队、冲突、外部改动的判断写成和界面无关的纯逻辑，放在 `@finx/client`，单独测试。
- 按会话还有：打开的标签和顺序、当前标签、目录树开没开、展开了哪些目录。

### 16.2 和方案不同的地方

- **目录树在右边**：编辑区在左、目录树在右，是用户在实现过程中定的。目录树开关跟着放到文件工具的最右端，用新画的文件树图标（`tree`）。
- **文件按钮的位置和图标**：面板打开时，顶栏的文件按钮移到面板标签条最右端，取代 ×，左边是放大（用户的要求）；图标仍是文件夹：曾短暂换成一页文件里上加下减，用户随即改回，因为这个面板看的是工作区文件，不是改动。浏览器面板也改成同样的做法：打开时地球按钮移到右上角取代 ×。
- **默认宽度**：文件面板比浏览器面板宽：占会话页宽度的 56%，最小 420、最大 960 像素；拖过的宽度单独记住。
- **目录树第一次是否显示**：面板宽度有 600 像素才显示，不够就先收起，点开关再打开。窄的时候代码会被挤得太窄。
- **路径栏**去掉了（2026-11-03）：它的按钮并进标签条，路径看标签的悬停提示。
- **标签**：宽度跟着文件名走（最多 200 像素），放不下时标签条横向滚动，不把每个标签挤成一两个字。
- **监听**：按系统给的真实路径对比（macOS 的 `/var` 实际是 `/private/var`），通知里给回请求时的路径。
- **查找面板**：中文界面下用中文文案（CodeMirror 自带的是英文）。
- **"打开方式"**：只是这一次用某个程序打开，不再记成默认；原来记默认编辑器的偏好（`openWith`）删掉了。
- **技能详情页的读取**：没有和 `files/read` 合并，各用各的，避免碰自定义页那边的代码。
