## 方案摘要

- **两种用法并存**：
  - 会话模式不变：以项目和任务为单位，一件事开一个会话，运行中可以插话、排队、停止。
  - Bot 模式是新增的：以"一个可以找的人"为单位。一个 Bot 只有一段对话，没有新建、没有归档，用户不用管理会话和上下文，像在聊天软件里找人办事。
- **Bot 只有名字和头像**：没有人设、没有说明、没有设置页、没有自己的技能。模型、技能、连接器都和会话共用。要它做什么，第一句话里说。
- **像聊天软件那样说话**：两边都是气泡，回复不流式。Bot 的每个气泡都是它主动"发给你"的一条消息，发的那一刻整条出现；它边做边想的字、做事的步骤都不进对话，想看再点"过程"。
- **一轮怎么回**：你一开口，Bot 先回你一句：能马上答就直接答，否则说一句它先做什么；做长活时在关键节点发简短的进展；做完把你等着的结果都发给你。几个要点分几条发。
- **一段对话里同时办几件事**：
  - 什么时候都能发，一次发几句也行。输入框只有"发送"，没有插话、排队、停止之分。
  - Bot 正在回上一句时，新的一句等它回完再接着回，每句都有回答。
  - 要花时间的，Bot 交给子智能体，自己接着跟你聊；子智能体做完，由 Bot 转告你。
  - Bot 忙的时候，对话最后是它的一个气泡，三个点在跳；有子智能体在做事时写着在做什么，点开看做到哪一步。
  - 要拍板的事，和会话模式一样，输入框上方弹出授权窗口，不进对话。
- **侧栏**：顶栏右端是 Bot 和会话两个图标的切换，默认 Bot 模式。Bot 列表像聊天软件：头像、名字、时间、最近一句、未读数；Bot 忙的时候头像在动。
- **默认 Bot**：第一次进 Bot 模式就有一个 FinxBot，头像是品牌的 α，不能删除。
- **分期**：一期做对话本身（§10）。二期：眼睛和对勾、引用按真实使用的需要做；Bot 调度会话模式（知道有哪些项目和会话，自己开会话、在已有会话里接着问，结果回到 Bot，§6.18）；定时提醒、记忆、系统通知、搜索。群聊放三期。

## 1. 背景

现在的产品以项目和会话为主：一件事开一个会话。会话越积越多，用户要自己决定在哪个会话里问、什么时候开新的、旧的要不要归档，其实就是在让用户管理上下文。对写代码这类事，这样做是对的：任务有边界，项目和分支就是上下文。

日常的事不是这样。一个问题、一个提醒、一件要查的事，常常几件一起冒出来。用户想要的是找个人说一声，而不是先想清楚开在哪个会话里。

所以 Bot 模式把长期存在的东西从"一段对话"换成"一个 Bot"：明天回来还是同一个 Bot，它还记得之前说过的事，用户只需要决定跟谁说。Bot 本身越简单越好，每多一个设置，就多一件要用户管理的事。

和会话模式最直观的不同：会话模式让你看它怎么做（流式的字、一步步的工具调用），Bot 模式只让你看它说了什么。

## 2. 目标、不做的事与验收口径

| 编号 | 目标 |
|---|---|
| G1 | 不用管理会话：一个 Bot 一段对话，没有新建、归档、上下文这些概念 |
| G2 | 像跟人聊天：随时发，一次发几件；几件事可以分几条回 |
| G3 | Bot 只有名字和头像，几秒钟建好一个 |
| G4 | 和会话模式共用一套能力（模型、技能、连接器、内核），来回切换不丢状态 |
| G5 | 一眼看出每个 Bot 在做什么、谁在等我、谁有新回复 |

**不做**：人设和自定义提示词、Bot 自己的技能、群聊（三期）、手机端。

**验收口径**：

- 发出一句后，0.5 秒内出现"它在忙"的气泡；能马上答的问题，从发出到回复的时间和在会话模式里直接问相当。
- 交出去的每件事都有结局：做完、没做成或者你让它停下，三者必居其一，不会悄悄消失。
- 不用学：第一次进 Bot 模式，不看任何说明，就能发消息，看得懂"它在忙"和授权窗口。

## 3. 场景

| 编号 | 场景 | 过程 |
|---|---|---|
| S1 | 随手问 | 问一句，点跳几秒，一个气泡回来 |
| S2 | 连着说几件 | 连发"写一首春天的诗"到"写一首冬天的诗"四句：Bot 回完一首接着回下一首，按顺序回来四个气泡 |
| S3 | 一快两慢 | 连发"查一下最近一年的 LPR 变化""把'季度复盘'翻成英文""把下载里的销售表按地区汇总"：翻译直接回；慢的两件 Bot 交给子智能体，"它在忙"写着"正在处理两件事"；子智能体做完，Bot 先后转告 |
| S4 | 交代一件长活 | "调研一下几家银行的企业网银费率"：Bot 交给子智能体；期间照常聊别的；点开"它在忙"看做到哪一步；做完由 Bot 转告 |
| S5 | 要拍板 | "nginx 挂了帮我看看"：它先说查到了什么，输入框上方再弹出授权窗口"重启 nginx"；允许后接着做，结果回来 |
| S6 | 不同的事找不同的 Bot | 研究员、运维、写作助手：列表里一眼看出谁在忙、谁在等你、谁有新回复 |
| S7 | 回来接着聊 | 第二天打开，还是那个 Bot，说"昨天那份汇总"它知道是哪份 |

## 4. 概念

| 词 | 意思 |
|---|---|
| Bot | 一个可以找的人：名字、头像，加上和你的一段对话 |
| 对话 | 和一个 Bot 的全部聊天记录。一个 Bot 只有一段，不新建、不归档、不清空 |
| 气泡 | 一条消息。你的在右边；Bot 的在左边，是它发给你的，发的那一刻整条出现 |
| 子智能体 | Bot 把要花时间的事交给它，在后台做，你可以接着跟 Bot 聊别的；做完 Bot 转告你 |
| 在忙 | Bot 正在回你的话，或者有子智能体在做事 |
| 授权窗口 | 弹在输入框上方，问你允不允许，和会话模式是同一个；不进对话 |
| 过程 | 一件事是怎么做的：一步一步的步骤，默认不显示 |
| 未读 | 你没在看这个 Bot 时，它发来的气泡数 |
| 眼睛、对勾（二期） | 你那个气泡上的小标记：这件事在做、这件事做完了 |
| 引用（二期） | 气泡里、字的上面一行，说明这条回复回的是哪句 |

## 6. 详细需求

### 6.1 模式切换

- **位置**：侧栏顶栏的右端。左边是交通灯和"隐藏边栏"，右边是全局的分段控件（`.seg`），只有图标：左边 Bot（机器人），右边会话（两个气泡），悬停显示名字。
- **默认**：新用户默认 Bot 模式。已经用过的，回到上次的模式。
- **切换时换什么**：只换侧栏的内容和内容区。
  - 导航三行的位置不变：会话模式第一行是"新会话"，Bot 模式是"新建 Bot"（Bot 模式下 ⌘N）；"搜索""自定义"两种模式都有。
  - 列表从同一个高度开始，切换时页面不跳；列表淡入一下（0.28 秒）。
- **各记各的**：切回会话模式回到刚才那个会话，切回 Bot 模式回到刚才那个 Bot；没发出去的字按会话或 Bot 分别保存。下次打开应用回到上次的模式。
- **提醒点**：另一种模式里有事时，那一段的图标右上角一个 6 px 的点。
  - 蓝点：有 Bot 回复了你还没看。
  - 橙点：有 Bot 或会话在等你确认。两者都有时显示蓝点。
- **快捷键**：先不做。

### 6.2 Bot 列表

- **一行一个 Bot**：行高 50（上下各 7，中间 36）。内边距、圆角、悬停和选中都和会话行一样。
- **第一行**：头像（36），名字（14），右端时间（11，灰）。今天的显示时刻，再往前是"昨天""周三""10月22日"。
- **第二行**（12，灰），按下面的顺序取第一个：
  1. 有确认在等："[待确认]"（橙）加要确认的事；几件都在等时，取最早的那件。
  2. 在忙：手上有事时是"正在处理两件事"，只在回话时是"正在输入…"，带流光。
  3. 都没有：最近一句话，谁说的都算；只有图片或文件时写"[图片]""[文件] 名字"；还没说过话时写"还没说过话"。
- **右端**：未读数，蓝底白字的计数；正在看的那个 Bot 不显示。
- **排序**：置顶的在前，然后按最近一句话的时间。正在做事不改变顺序，否则行会一直跳；新气泡来了，这一行才挪到上面。
- **右键菜单**：置顶（或取消置顶）/ 重命名 / 删除 Bot。默认 Bot 不能删，没有"删除 Bot"。行上没有按钮。
- **重命名**：在列表里原地改，名字变成输入框，↩ 或点别处保存，Esc 取消；双击这一行也可以。改头像在 Bot 设置里（§6.5.1）。
- **数量**：不设上限。列表不分组、不筛选，Bot 多了靠置顶和搜索（DQ-53）。

### 6.3 新建与编辑 Bot

- **入口**：导航的"新建 Bot"。建好之后改名字和头像在 Bot 设置里（§6.5.1）。
- **表单**（sheet，440 宽）：
  - 标题"新建 Bot"，下面一句说明："起个名字，挑个头像。要它做什么，直接在对话里说。"
  - 头像预览（64），右边是名字输入框，占位字"比如：研究员"。
  - 头像选择：8 个小角色加一个"名字的第一个字"，下面一排 8 个颜色。左下角"上传图片…"。默认 Bot 多一个 α 可选。
  - 底部：取消、创建。名字为空时"创建"是灰的。
- **默认值**：新建时随机配好一个小角色和颜色，所以只填名字、按 ↩ 就能建好。
- **名字**：去掉首尾空白，1 到 20 个字。可以和别的 Bot 重名（DQ-58）。
- **上传图片**：png、jpg、heic，最大 10 MB；裁成正方形，存一份 256 px 的。
- **建好以后**：列表最上面多一行并选中它，打开它的空白页（§6.15），光标在输入框里。
- **头像的样子**：
  - 形状是圆角方块，和窗口的方正一致，圆角按尺寸取 `--r-xs` 到 `--r-xl`。
  - 颜色是一组压低了饱和度的中间色，深浅主题下都不变，像照片一样。
  - 小角色是白色的简单形状加两只眼睛，在 22 px 下也认得出来。

### 6.4 默认 Bot

- 第一次进 Bot 模式时，已经有一个叫 FinxBot 的 Bot，头像是品牌的 α（墨色底）。
- 不能删除，可以改名字、换头像（之后也能换回 α；α 只给默认 Bot 用）。
- 除此之外它就是普通的 Bot。它保证 Bot 模式从来不是空的。

### 6.5 对话页：顶栏

- 中间：头像（22）和名字，像聊天软件里的好友。Bot 在忙时头像在动（§6.12）。
- 不写状态：在做什么看列表那一行和对话里"它在忙"的气泡，要确认的看输入框上方的确认窗口。
- 头像和名字是一个按钮：悬停时出现底色和一个右箭头，箭头不占位，所以它们总在正中间。点一下打开 Bot 设置（§6.5.1），再点一下关上。
- 右边：内置浏览器、文件面板（和会话页相同，开着时按钮在面板右端）。没有 ⋯。
- 没有会话页的信息卡：环境和上下文都不用用户管。

### 6.5.1 对话页：Bot 设置

和 Bot 有关的设定都在这里。它在页面右侧滑出，宽 340，和文件面板、内置浏览器共用一个位置，同时只开一个。样式像 iOS 和 macOS 的设置页：上面是头像和名字，下面是一组组圆角的行。右上角 × 关闭。

- **头像**：72，居中。悬停时变暗并显示铅笔。点一下在名字下面展开选择：小角色、名字首字、颜色、"上传图片…"（默认 Bot 还有 α）。选了马上生效，列表和顶栏同时变。再点头像收起。
- **名字**：头像下面。双击变成输入框，↩ 或点别处保存，Esc 取消。
- **模型设定**：
  - 模型：这个 Bot 回话用的模型，菜单和输入框下方的模型菜单是同一个（按服务商分组、搜索、最近用过）。没有 Key 的模型，选了会先要 Key。
  - 思考强度：这个模型提供的档位和"默认"。模型不提供档位时没有这一行。换模型时档位的规则和会话页相同（模型目录方案 §18）。
  - 下面一句说明：只影响这个 Bot。新建的 Bot 从全局默认模型开始。
- **权限**：权限模式一行，三档和会话相同；下面说明当前这档的意思，以及只对这个 Bot 生效、它创建的智能体和任务都按这个权限运行、改了立刻跟着变。默认和第一次的提示见 §6.13。
- **删除 Bot**：红字一行，确认框同 §6.16。默认 Bot 不能删，没有这一行。删除后面板关上。
- 切到别的 Bot 时面板留着，内容换成那个 Bot 的。点开文件、链接时，文件面板或浏览器接过这个位置，面板收起。

### 6.6 对话页：消息与气泡

- **你的话**：右边的气泡，和会话页一样。图片和文件显示在气泡上方。
- **Bot 的话**：
  - 在左边的气泡里，底色比窗口深一级（`--win2`），加一条细边。旁边没有头像，连续几个气泡读起来是一段。
  - 气泡最宽 640。Markdown、代码块、表格、文件标签、链接都照旧，显示在气泡里；代码块和表格放不下时在气泡里横向滚动。
  - 文件标签左键在文件面板打开，PDF 进文档栏；链接在内置浏览器打开；右键菜单和会话页一样。这些都和会话页同一套，Bot 也能操作内置浏览器。
- **不流式**：Bot 的每个气泡都是它主动发给你的一条消息，发的那一刻整条出现，有一个很短的进场动画（0.4 秒淡入上移）。没有一个字一个字往外冒的过程；它边做边想写的字不显示，只在"过程"里看得到。
- **一轮怎么回**：
  - 你一开口，Bot 的第一件事是回你一句：能马上答就直接答；要花时间就说一句它先做什么（"在查了。"），不拿没核实的话凑数。
  - 做长活时，在有意义的节点发简短的进展：有了一个结果、做了一个决定、卡住了、计划变了。不逐条播报命令，不播报重试。
  - 做完时，把你等着的结果都发给你，这一轮才算完。"在查了"不算交付。
  - 几个不同的要点分几条发；一个答案不拆成碎片。
  - 子智能体的汇报回来时，不用先回一句；值得告诉你才发。
  - 说话像懂行又热心的朋友：先给答案，通常一两句；不提工具名、消息编号这些内部的东西。
- **顺序**：对话按发出的时间排。Bot 正在回时你发的话，就排在你发出的那一刻，重新打开对话也不挪位置。
- **间距**：同一个人连发的几个气泡挨得近（6），换人才隔开（21）。
- **悬停**：时间和按钮出现在气泡外侧，不占气泡下面的位置，连续的气泡才能挨在一起。你的在左边：时间、拷贝。Bot 的在右边：时间、拷贝，做过事的还有"过程"；二期加"引用回复"。
- **时间分隔**：停顿 10 分钟以上，中间一行时间，例如"今天 22:14""昨天 09:40"。
- **历史**：打开时显示最近的部分，往上滚动时再加载更早的；一段对话可以很长，不分页、不折叠。

### 6.7 它在忙：最后一个气泡

- 只要 Bot 在忙，对话的最后就是它的一个气泡，里面三个点在跳。
  - 在回你的话时，只有点。
  - 有子智能体在做事时，点后面写着在做什么：一件事时是这件事的名字（Bot 交给子智能体时起的），几件事时是"正在处理两件事"，后面一个小三角。
- **点开**：
  - 只有一件事时，看到的是它的步骤：做过的是灰的，正在做的那一步在流光里，后面是做了多久（"4 分 56 秒"）。
  - 有几件事时，一件一行：名字、正在做的那一步、做了多久。
- 它总在最后，新消息和新回复都排在它上面。不忙时，这个气泡不出现。
- Bot 回完这一句、子智能体还在做事时，这个气泡留着，输入框照常能用：它在等的是子智能体，不是你。
- 等你确认的事不算在忙；只剩等确认的事时，这个气泡不出现。

### 6.8 眼睛与对勾（二期）

一期没有这些标记：交给子智能体的事，在"它在忙"的气泡里看得到，做完由 Bot 转告。二期按下面的样子做：

- 要花时间的事，Bot 接手时（发出后一秒左右）在你那个气泡的左上角放一只眼睛（22 px 的圆形标记），意思是"看到了，在做"。它不再回一句"好的，我去弄"。
- 做完时，眼睛换成绿色的对勾，结果作为一个新气泡回来。
- 没做成时，眼睛换成橙色的感叹号，Bot 发一个气泡说明原因，下面一个"重试"（§7）。
- 你说"那个不用了"，它停下那件事，去掉眼睛，回一句已经停了。界面上没有停止键（DQ-49）。
- 能马上答的话不放眼睛，直接回。
- 悬停标记时有提示："研究员 正在处理""研究员 做完了""研究员 没做成"。

### 6.9 连发

- 什么时候都能发，一次发几句也行。
- **不打断任何东西**：Bot 正在回时，新的一句等它做完手上这一步，紧接着送达，Bot 接着回。已经开始发的气泡总是完整发出。连发四首诗，Bot 一首发一条，按顺序回来四个气泡；几句恰好同时送达，也是分几条发。
- **要花时间的事在后台**：Bot 先回一句，把活交给子智能体，这一轮就结束了，所以你的下一句几乎不用等；子智能体不受新消息影响。写一万字的作文时，你可以一直跟它聊，写好了它再发给你。
- **问进度**：你问"写到哪了"，它看过实际情况再回答，不会直接说一句"还在做"。
- **不想要了**：直接说，怎么说、用什么语言都行。Bot 先让子智能体停下，确认停了才说停了。要改要求（"写短点"），它转告同一个子智能体。
- **改主意的时候**：它正在写的回答照样发出，下一步读到你的话再回应，和跟人聊天时刚好错过一样。活都在后台，这种回答都很短。

### 6.10 引用（二期）

引用在气泡里、字的上面：一行一句，左边一条竖线。点一下回到原句，原句闪一下。能省就省，和人聊天一样：

- 你连着发的几句，Bot 按顺序一句一个气泡回答时，不引用。交出去的（带眼睛的）那几句不算在这个顺序里。
- 交出去的事做完回来时，紧挨着那句就不引用，隔开了才引用。
- 回答的顺序和你发的对不上（先回了后面的），这一轮之后的回复都引用。
- 你也可以引用 Bot 的某一条来回复：悬停，点"引用回复"。那条出现在输入框里、字的上方，点 × 去掉；发出去的气泡里带着这条引用。

### 6.11 过程

- 它做事的步骤（思考、工具调用）不进对话。
- 想看时，悬停那条结果，点"过程"：气泡下面展开会话页那种步骤卡，第一行是"用时 7 分 52 秒 · 6 步"；再点一次收起。一个气泡的过程，是从上一个气泡到它之间做的事。
- 子智能体交来的汇报，在过程里是一步。
- 正在做的步骤，点开"它在忙"的气泡看（§6.7）。

### 6.12 头像在动

- Bot 在忙时，它的头像在列表和顶栏都在动：小角色左右看，偶尔眨一下眼；α 和名字首字的头像一呼一吸。上传的图片不动。
- 不另加状态点：扫一眼列表，在动的就是在忙的。
- 系统设置了"减少动态效果"时都不动。

### 6.13 授权窗口

- 要拍板的事（危险命令、对外发消息、花钱……沿用现有的权限规则），输入框上方弹出授权窗口，和会话模式是同一个：写着要做什么、具体的命令或改动，按钮和快捷键也相同（允许一次、本会话都允许、不允许并可写原因，⌘↩ 允许）。授权是对话之外的操作，不是 Bot 说的话，所以不进对话。
- 答过以后窗口收起，对话里不留痕迹；那一步在"过程"里看得到。
- 几件事同时要确认时（Bot 和它的子智能体都算），一次只弹一件，答完弹下一件，按提出的先后；列表那一行显示正在问的那件。
- 列表里那一行显示"[待确认] …"，切换按钮上出现橙点。
- 不允许时，Bot 回一句它接下来怎么办。
- **权限模式**：和会话相同的三档（询问权限、自动接受编辑、完全访问），在 Bot 设置里选（§6.5.1），每个 Bot 各记各的；切到完全访问时和会话一样先确认。
- **影响范围**：一个 Bot 的权限对它创建的智能体和任务同样生效，改了连还在运行的也立刻跟着变（子智能体方案 §10.4）。第一次的提示、设置里的说明、切到完全访问的确认框三处都写明这一点，因为这些操作主人看不到每一步。
- **默认完全访问**：所有 Bot 默认完全访问，已有的对话和新建的 Bot 都是；进页面不弹窗。在某个 Bot 的设置里选的，那个 Bot 一直按选的来。
- **第一次的提示**：权限藏进设置后，页面上看不到它，所以第一次看到完全访问的 Bot 时，输入框上方弹出一张提示，和关键提醒、授权窗口同一个位置、同一个形状。标题"Bot 默认开启完全访问"，正文"任何系统操作将不再经过你的授权同意，它创建的智能体和任务也一样。每个 Bot 各有一份设置，你随时可以调整：点顶部的名字就能打开。"，按钮"打开设置"和"知道了"。
  - 它占自己的位置，不盖输入框，所以写字、发消息都不收起，一直留到主人回应。
  - 点"知道了"收起；打开 Bot 设置也算看过，不管是点这张提示的按钮还是顶部的名字。收起后所有 Bot 都不再出现。
  - "打开设置"把面板拉到右边，主人看一眼就知道权限在哪。
  - 有授权窗口时先显示授权窗口。
- **子智能体要确认时**：弹的是同一个窗口，窗口上写着"子智能体 · 它在做的事"；Bot 不能替你答。等你答的时候 Bot 照常回话，你可以接着跟它说别的。不允许只拦这一步，子智能体接着做，做完由 Bot 转告。选"本会话都允许"，Bot 和它的子智能体都不再问同类的事。

### 6.14 输入框

- 用会话页的同一个输入框，下面没有那一行：模型和权限都在 Bot 设置里（§6.5.1、§6.13）。
- ＋ 菜单照旧：文件、图片、技能、连接器。
- 占位字："发消息给 研究员"。↩ 发送，⇧↩ 换行。只有"发送"：没有 ⌥↩ 排队，也没有停止键。
- 没发出去的字按 Bot 保存，切走再回来还在。
- 二期引用回复时，引用显示在字的上方（§6.10）。

### 6.16 菜单与操作

| 操作 | 怎么做 | 说明 |
|---|---|---|
| 改名字、换头像 | 在 Bot 设置里（§6.5.1） | 改完列表和顶栏马上变；之后 Bot 以新名字自称 |

### 6.17 未读与提醒点

- 你没在看某个 Bot 时，它发来的每个气泡和每次要你确认都记一条未读。
- "在看"是指：窗口在前台，并且选中的就是这个 Bot（DD-122）。窗口在后台时来的气泡算未读，回到窗口就清零。
- 打开这个 Bot 就清零。
- 正在看这个 Bot 时，新气泡不算未读，即使你往上翻着；这时"回到底部"按钮出现（和会话页一样）。
- 模式切换按钮上的点见 §6.1。

### 6.18 Bot 和项目、会话（二期）

一期不处理：一期的 Bot 和无项目会话一样，在自己的文件夹里干活，做出来的文件放在那里；要动某个项目，在对话里说路径。

二期，Bot 能调度会话模式：

- **知道有哪些项目和会话**：会话模式里用过的项目、每个项目里的会话（标题、在做什么、最后说到哪），Bot 自己就看得到，不用主人告诉它路径。
- **自己开会话**：项目里的活，Bot 在那个项目里新开一个会话去做。会话有完整的项目上下文（指令文件、技能、项目配置）。
- **在已有的会话里接着问**：比如"让修 CI 的那个会话再把测试补上"，Bot 找到那个会话，把话发进去。会话正在忙时排在后面，不打断。
- **会话回报给 Bot**：会话做完、卡住、要确认时，消息回到 Bot。Bot 把结果转成主人关心的几句告诉主人，气泡里带一张会话卡片（标题、项目、状态），点一下切到会话模式打开它；也可以接着安排下一步。
- **互相通信**：会话之间不直接说话，经由 Bot 转达和安排。

主人看到的：

- 会话模式的列表里，Bot 开的会话标着 Bot 的小头像；会话页里，Bot 发进来的话旁边标着 Bot 的头像和名字。
- 会话里要确认的事，会话页和 Bot 页都弹授权窗口，哪里先答复算哪里。Bot 自己不能答复确认。
- Bot 只能看会话、开会话、发消息；不能改会话的模型和权限，不能归档、删除、改名。它碰过的会话都在会话列表里。

和子智能体的分工：不属于任何项目的活（查资料、整理、写东西）照旧交给子智能体；项目里的活交给会话。两者的结果都由 Bot 转告。

### 6.19 和会话模式的关系

- **共用**：模型连接、默认模型、权限设置、技能、连接器、内置浏览器、电脑操控。
- **分开**：Bot 的对话不出现在会话列表里，会话也不出现在 Bot 列表里。搜索（⌘K）在两种模式里各搜各的：一期 Bot 模式下按名字和最近一句找 Bot，搜所有聊天记录（F22）在二期。
- **调度会话**（二期）：见 §6.18。

| 功能 | 期 | 要点 |
|---|---|---|
| 定时与提醒 | 二 | "明早 9 点提醒我看周报"：到点 Bot 在对话里发一条；也可以定时做一件事（每天早上整理邮件）。一期的 Bot 不答应提醒，会直说还做不到（原型里的提醒是二期的示意） |

## 7. 异常与边界

| 情况 | 用户看到的 |
|---|---|
| 模型在自动重试（限流、网络） | "它在忙"的气泡照常跳；超过 10 秒，点后面加一行灰字"连接不稳，正在重试" |
| 自动重试用完 | Bot 一侧出现一张失败卡（会话页的失败卡样子）："这几句没回上：DeepSeek 要求放慢速度"，右边"重试" |
| 子智能体没做成 | Bot 转告原因，问你要不要再试 |
| 你拒绝了确认 | 窗口收起，Bot 回一句接下来怎么办 |
| 你让它停下一件事 | Bot 让子智能体停下，回一句已经停了 |
| Bot 这一轮什么也没回 | 内核提醒它一次，它再回（技术方案 §3.11）。验收时短问题有四成多是这样，提醒后几乎都回了（108 个任务里漏 2 个）。提醒过还是没回，点不再跳，没有新气泡。提醒过还是没回：失败卡"这次没有收到回复"，可以重试或换模型 |
| 应用退出时 Bot 在忙 | 事情在后台接着做；再打开时结果已经在对话里，列表上有未读 |
| 内核重启或崩溃 | 正在回的那句和子智能体的事被中断；重开后 Bot 的状态和子智能体的结果以会话日志为准，没做完的需要你再说一声 |
| 删除时还有事在做 | 手上的事会停下，确认框写明（§6.16） |
| Bot 很多 | 不限数量，列表滚动；靠置顶和搜索 |
| 很长的回复 | 气泡最宽 640，照常换行；代码块、表格在气泡里横向滚动 |
| finx 没启动 | 列表区显示和会话模式一样的"finx 没启动"；输入框不能发送 |
| 名字被改了 | 之前的气泡不变；之后 Bot 以新名字自称 |

## 11. 验收标准

一期逐条验收，用真实模型：

1. 切换：两种模式来回切，各自回到原来的会话或 Bot；没发出去的字还在；重开应用回到上次的模式。
2. 列表：新回复来时那一行挪到上面、未读加一；打开清零；在忙时第二行和头像都在动；有确认时显示"[待确认]"。
3. 新建：只填名字按 ↩ 就能建好；上传的图片显示为头像；默认 Bot 不能删除。
4. 不流式：任何时候对话里都看不到写了一半的回复。
5. 连发四首诗：按顺序回来四个气泡，一首一个。
6. 先回一句：每句发出后很快有一个回应气泡，答案或者"在做什么"；要花时间的，做完再来一条结果。
7. 不漏内部的东西：气泡里不出现 Bot 边做边想的字、工具名、消息编号。
8. 一快两慢：快的直接回；慢的两件 Bot 交给子智能体，"它在忙"写着"正在处理两件事"，点开看到每件的进度；子智能体做完，Bot 先后转告。
9. 后台的事不被打断：子智能体在做事时连发几句别的，Bot 照常回，子智能体照常做完。
10. 停下：说"那个不用查了"，子智能体停下，Bot 回一句。
11. 确认：Bot 默认完全访问，不弹窗，输入框上方有一次提示，点"知道了"或打开设置后不再出现；在 Bot 设置里可以改，改了留住；询问权限时，允许后接着做完；子智能体要确认时弹同一个窗口，写明是哪个子智能体，等的时候 Bot 照常回话；不允许时 Bot 回一句；列表和切换按钮的提示随之消失。
12. 失败：断网或限流到重试用完，出现失败卡，点"重试"能接着回。
13. 应用退出时在忙：重开后结果已经在对话里，有未读。
14. 过程：悬停结果点"过程"，展开它的步骤和用时。
15. 顺序：Bot 回话中途发的话，关掉对话再打开，位置不变。
16. 改名：改名后，Bot 下一次回话以新名字自称。
17. 深浅主题、减少动态效果下都正常。
18. Bot 设置：头像和名字在顶栏正中，悬停有箭头，点开右侧面板；换头像马上生效；双击改名字；换模型和思考强度后，下一次请求用的就是它们，finx 重启后还在，别的 Bot 不受影响。

## 14. 原型

- **文件**：docs/desktop/bot-mode-demo.html。用 .claude/launch.json 的 `desktop-demos-main`（端口 8768）打开。
- **样式**：应用的真实样式（tokens.css、app.css、composer.css 原样内联）。会话模式那一边是运行中应用的静态快照，只用来看切换效果。
- **左下角的面板**：
  - "给 FinxBot 连发三件事"：两件要花时间的，气泡上出现眼睛；一件马上回。最后的气泡写着"正在处理两件事"，点开看每件做到哪。做完的先后回来、带着引用，眼睛换成对勾。
  - "连发四首诗"：点一直在跳，最后按顺序回来四个气泡，不加引用。
  - "让研究员交差"：在别的页面时有回复进来，列表出现未读数，切换按钮上出现蓝点。
  - "新建 Bot""重来"，以及浅色和深色的切换。
- **确认卡已废**：原型里的确认卡是 v2.2 之前的做法，现在以 §6.13 为准。
- **原型是完整的设计目标**：其中眼睛和对勾、引用、提醒的样子属于二期，"顶掉"不做了（DD-134）；一期的子智能体由 Bot 转告结果，没有标记和引用。
- **回复是脚本**：那几句有写好的回复；随手发的话，寒暄、提醒和短问题马上回，别的都当成要花时间的事，结果是一段占位文字。失败、感叹号、提醒的真实行为原型里没有做。
